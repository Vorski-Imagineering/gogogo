# Security

Report a vulnerability privately through this repository's **Security → Report a
vulnerability** (GitHub private vulnerability reporting). Please do not open a
public issue.

In scope:

- anything that lets the unattended loop merge, deploy, or write to a board or
  repo that the rules say it must not;
- a script that leaks a credential.

Out of scope: how a repository's own profile (`.agents/dev-process.md`) is
written.
