We use gogogo's wrap-up process here. Its worktree check printed a remove line for a worktree whose pull request has merged, so it is about to ask me whether to remove it. Before the options, what does that question tell me? Answer in two or three sentences, in the process's own terms, change nothing, and end with one line `Before the options: what it is, reach, run time` or `Before the options: the worktree's path only`.
