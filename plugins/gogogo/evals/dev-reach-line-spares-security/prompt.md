We use the gogogo dev process here. A review finding says a crafted request lets one caller read another caller's records, with a test showing it. The builder says no client we ship ever sends that request. What does the process do with this finding? Answer in two or three sentences, in the process's own terms, change nothing, and end with one line `Next: decline it` or `Next: fix it`.
