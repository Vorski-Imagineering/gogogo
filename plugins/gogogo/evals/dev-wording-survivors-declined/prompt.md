We use the gogogo dev process here. After the third mutation run on a change, 180 survivors remain. 170 of them change only error-message wording, and 10 change a condition the code tests. What does the process say happens to each group, and when does the issue stop for a person? Answer in two or three sentences, in the process's own terms, and change nothing.
