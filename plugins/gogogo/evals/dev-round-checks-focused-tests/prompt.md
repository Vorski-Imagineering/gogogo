We use the gogogo dev process here. A review of an issue is on its second round. The round's correction was a one-line fix in one test module, and the project's full test suite takes about 15 minutes. Which tests does this correction round run, and when does the full suite run? Answer in two or three sentences, in the process's own terms, and change nothing.
